# Project instructions

This repository uses AIDDbot skills from `.agents/skills/`. Follow the linked
`SKILL.md` for the task; do not invent a workflow.

## Starting point

- Product documentation and specifications belong in `.product/` until `/explore`
  confirms different paths.
- Application code belongs in direct child folders such as `back/`, `front/`,
  `cli/`, or `e2e/`; do not create one until the selected scaffold or design
  names it.
- Preserve existing work. Never overwrite a non-empty project folder, expose
  secrets, or use destructive commands.
