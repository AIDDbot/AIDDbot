# s0007 - Set the first development version and add README badges

## Problem

### Goal

Identify the first development version and help readers find the previous AIDDbot project.

### User story

- `US1` - As a reader, I want to see the current development version and codename and find the archive from the README, so that I can identify both versions of the project.

## Solution

Set `version` to `0.0.1` and `codename` to `thanksgiving` in the root `package.json`. Add blue version and orange codename badges below the README title. Both read the root manifest and link to it. Add `AIDDbot-legacy` to the README's project links.

## Verification

- [x] `US1R1` - When a reader opens the root manifest, it shall show version `0.0.1` and codename `thanksgiving`.
- [x] `US1R2` - When a reader opens the README, it shall show badges that read both fields from the root manifest and a link to `AIDDbot/AIDDbot-legacy`.
