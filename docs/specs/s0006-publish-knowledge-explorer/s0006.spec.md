# s0006 - Publish the AIDDbot knowledge explorer

## Problem

### Goal

Publish the existing explorer as the public documentation for AIDDbot and its development process. Make this repository the official project and preserve the previous version as an archive.

### User stories

- `US1` - As a person learning AIDDbot, I want to explore its method and development in a browser, so that I can see how the project applies its own method.

## Solution

1. Rename the previous repository to `AIDDbot/AIDDbot-legacy`. Publish this repository and its history as `AIDDbot/AIDDbot` and set the local `origin` to it.
2. Use GitHub Actions to install the locked Bun dependencies, build the explorer, and publish `packages/explorer/dist/` to GitHub Pages on pushes to `main` and manual runs on `main`. Link the public explorer from the README.
3. After verifying the site, link the legacy README to the new repository and archive the legacy repository.

## Verification

- [x] `US1R1` - When a visitor opens `https://aiddbot.github.io/AIDDbot/`, the public explorer shall show the method overview and let the visitor open the project plan and a completed spec without signing in.
- [x] `US1R2` - When a push reaches `main` or a maintainer runs the workflow manually on `main`, GitHub Actions shall build and publish the explorer after a successful build.
- [x] `US1R3` - After the cutover, GitHub shall serve this project at `AIDDbot/AIDDbot` and the previous project as a public archive at `AIDDbot/AIDDbot-legacy` with a README link to the successor.
