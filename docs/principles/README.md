# Principles

These principles drive the technical design of each system. They have no technology. An archetype adds the technology.

Read them from the largest scope to the smallest:

1. [System](./system.md): the projects, the REST API and the security.
2. [Project](./project.md): the archetype, the containers and the composition.
3. [Feature](./feature.md): the layers.
4. [Data](./data.md): the types, the shared utilities and the schemas.
5. [Coding](./coding.md): the names, the conditions, the errors and the scope.
6. [Complexity](./complexity.md): the limits and the functions.
7. [Scaffolding](./scaffolding.md): the names of files and folders, and the tree.
8. [Verification](./verification.md): the checks, what blocks a delivery, and the tests.

See the [Glossary](./glossary.md) for the terms.

The [engineering principles](../engineering/README.md) drive the management of the development.
