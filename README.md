## Build software you can trust.

`AIDDbot` is a set of agent skills for **AI-Driven Development**.

You tell your coding agent what you need. The agent writes a spec, waits for your approval, writes the code and the tests, proves the behavior, and releases a version.

The models do only the work that needs judgment. A deterministic core runs the tests, keeps the evidence and enforces the rules: more reliable, faster and cheaper than a model.

## Install

Your repository can be a new **greenfield** project or an existing **brownfield** (legacy) codebase. In its root folder, run:

```bash
npx github:AIDDbot/AIDDbot init
```

You need Node.js, Git, and Claude Code, Codex, GitHub Copilot or Cursor with a model from 2026 or later.

## Use

Open your coding agent in the same folder. Then use these three commands:

| Need | Command |
| --- | --- |
| Start a greenfield system, or document a brownfield one | `/architect-system-foundation` |
| Deliver a change | `/build-requested-spec your request` |
| Repair technical debt | `/craft-lasting-quality` |

> In Codex, use `$` instead of `/`.
