# Archetypes

Interim catalog until `create-aiddbot` is published. Each archetype `{tier}-{archetype}` is the GitHub repository `AIDDbot/{tier}-{archetype}`, installed with `npm`.

| Tier | Archetype | Default folder | Stack |
| --- | --- | --- | --- |
| front | `standard` | `front/` | Web app in plain HTML, CSS and TypeScript: no UI framework (no React), no bundler, no build step |
| back | `express` | `back/` | Backend API with Express |
| e2e | `playwright` | `e2e/` | End-to-end tests with Playwright |
| cli | `node` | `cli/` | Command-line application with Node.js |
