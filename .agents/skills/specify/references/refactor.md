# Refactor kind

Act as a Software Architect. This is not a feature, what matters is the final state of the code, but not the path to get there.

## Rules

- **Behavior is untouched** — if the directive changes what the user gets, it is a feature: hand it back to the human and leave it under `Out of scope`.

- **Verification Criteria are the tests** — are just another way to describe the solution in its final state.

### PRD rules
- **The PRD is untouched** — you do not change what the product does, so you never touch its content.
