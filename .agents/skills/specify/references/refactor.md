# Refactor kind

This is not a feature. What matters is the final state of the code, not the path to get there.

Behavior is untouched. If the directive changes what the user gets, it is a feature: put it under `Out of scope` and tell the human.

Verification Criteria are just another way to describe the solution in its final state.

The PRD is untouched — you do not change what the product does.
